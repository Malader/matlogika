Начнём со слов: «каждый» и «хотя бы один»

Сегодня учимся точно записывать обычные фразы и проверять, верны ли они. Новые буквы будем вводить по одной, после примера.

Упр. 1Что нужно знать, чтобы ответить «да» или «нет»устно, 2 мин

Вспомним три вопроса. Когда неверно «если A, то B»? Что значит «не выполнены A и B одновременно»? Можно ли проверить «x меньше 3», не зная x?

знаки в этой задаче→ если …, то …¬ не& и< меньше
A → B ¬(A & B) x < 3

«Если A, то B» нарушено только тогда, когда A выполнено, а B — нет. Например: «Если число равно 2, то оно нечётное». Подставим 2: условие «число равно 2» выполнено, а вывод «оно нечётное» — нет. Для этой подстановки утверждение ложно.

«Не выполнены обе части одновременно» означает, что хотя бы одна часть неверна. Обе неверные части тоже подходят. Требовать неверности обеих не нужно.

Для x < 3 нужно подставить число: при x = 1 ответ «да», при x = 5 — «нет».

Ещё вопрос: «Существует число меньше нуля» — верно? Среди 0, 1, 2, … — нет. Среди целых чисел — да: подходит −1. Значит, сначала надо договориться, какие числа разрешено выбирать.

главный порядок

5-17 мин

1. Договоримся, что означают буквы

Один числовой пример останется с нами почти весь семинар. По нему различим вычисление числа и проверку утверждения.

Берём числа 0, 1, 2, 3 и так далее. Их множество назовём M. Это наша область: все переменные будут получать числа именно отсюда. Буква x — место, куда можно подставить одно из этих чисел.

M = ℕ = {0,1,2,3,…}       разрешённые числа, включая ноль

c       обозначает число 0.
f(x)    прибавить к x единицу.
P(x)    проверить: x чётное?
R(x,y)  проверить: x меньше y?

f(2) = 3       получили число.
P(2) — да.     P(3) — нет.
R(2,5) — да.   R(5,2) — нет.

Спросить: «Чем отличается ответ у f от ответа у P и R?» Дождаться: f возвращает число; P и R дают ответ «верно» или «неверно».

Теперь названия. f — функция: по одному числу получаем другое. P и R — предикаты: они проверяют свойство или отношение. c — константа: обозначает один выбранный предмет, здесь ноль.

Чтобы записать P, нужно одно число. Чтобы записать R, нужны два, причём их порядок важен: 2 меньше 5, но 5 не меньше 2. Количество нужных чисел называют числом аргументов, или местностью.

Сигнатура — разрешённые обозначения:
  P¹ — проверка с одним аргументом;
  R² — проверка с двумя аргументами;
  f¹ — функция с одним аргументом;
  c  — имя одного предмета.

σ = ⟨P¹, R², f¹, c⟩     верхние цифры — не степени!

Система 𝔄 — область M + выбранный смысл этих букв.
Наша 𝔄: числа ℕ, чётность, «меньше», «прибавить 1», ноль.

Список букв сам по себе не говорит, что R означает «меньше». Такой смысл мы назначили отдельно. Это назначение называется интерпретацией. В другой системе R может означать «делится на».

Связь с методичкой. Определения 3.1–3.4, стр. 37–38. M² — все упорядоченные пары чисел из M. Отношение можно задать списком подходящих пар: для «меньше» (2,5) подходит, (5,2) — нет. R𝔄 означает «конкретное отношение R в системе А»; σ читается «сигма».

Два условия на весь семинар. Область непустая. Функция должна по каждому разрешённому входу вернуть ровно один предмет из этой же области. На M = {0,1,2} правило «прибавить 1» не подходит: из 2 получится 3, которого в области нет.

Сначала вычисляем: c = 0, f(c) = 1. Значит, первая запись спрашивает про R(0,1), вторая — про P(1).

2. Получить число или проверить утверждение?

Это два разных действия. Термины «терм» и «формула» обозначают именно эту разницу.

c             это 0.
f(c)          прибавили 1: получили 1.
f(f(c))       ещё прибавили 1: получили 2.

P(f(f(c)))    теперь проверяем: 2 чётное? Да.

Терм:     обозначает предмет.  В нашем примере — число.
Формула:  что-то утверждает.   Проверяем: истина или ложь?

Запись f(f(c)) не бывает истинной или ложной: она обозначает число 2. Если добавить P, получим утверждение «2 чётное». Вот его уже можно проверить.

Одна переменная x и одна константа c тоже считаются термами. Из термов можно строить новые термы с помощью разрешённых функций. Проверки P(x), R(x,y) и равенство x = c — формулы.

Такую отдельную проверку называют атомарной формулой. Из формул дальше собираем более сложные: соединяем через «и», «или», «если», добавляем «не», «для каждого», «существует».

Это определения 3.6–3.7, стр. 38–39. Правильно составить запись и проверить её истинность — разные задачи. У ошибочно составленной записи сначала надо исправить устройство.

3. «Каждый» и «существует»: два способа проверки

Сначала смысл двух слов. Затем перевод фраз и порядок выбора чисел.

«Все числа чётные» — ложь: подходит возражение «а число 1?». «Есть чётное число» — истина: достаточно показать число 2. Для этих двух слов в логике есть специальные знаки — кванторы.

∀x P(x)   «Каждое число x чётное». Ложь: 1 нечётное.
∃x P(x)   «Есть чётное число x».   Истина: подходит 2.

∀x — «для каждого x». Проверка должна пройти для всех.
∃x — «существует хотя бы один x». Достаточно одного.

Выбираем x только из нашей области M.

Подходящий предмет называют свидетелем. Для ∃ достаточно одного свидетеля, но их может быть много. Знак не означает «ровно один». Чтобы опровергнуть ∀, достаточно одного неподходящего предмета; чтобы опровергнуть ∃, надо показать, что не подходит ни один.

Упр. 5Переводим фразы про студентов и задачи2 мин самостоятельно, 4 мин разбор

Здесь новый пример и новый словарь. Вместо чисел область содержит людей и задачи.

S(x): x — студент.
T(y): y — задача.
L(x,y): x решил y.

Записать три фразы:

  1. Каждый студент решил хотя бы одну задачу.
  2. Есть студент, не решивший ни одной задачи.
  3. Каждую задачу решил хотя бы один студент.

1. Берём любой предмет x. Если это студент, ищем задачу y, которую он решил.

∀x (S(x) → ∃y (T(y) & L(x,y)))

Слева S(x) →: «если x студент». Это нужно, потому что в области есть и сами задачи: от задачи не требуем решать другие задачи. Справа T(y) & L(x,y): y должна быть задачей, и студент должен её решить.

2. Ищем человека x: он студент, и нет ни одной задачи y, которую он решил.

∃x (S(x) & ¬∃y (T(y) & L(x,y)))

Внутреннее ¬∃y читаем «не существует y». Получаем «не существует решённой им задачи».

3. Берём любую задачу y. Для неё ищем решившего её студента x.

∀y (T(y) → ∃x (S(x) & L(x,y)))

Проверка: один студент решил все задачи, остальные — ничего. Тогда пункт 3 верен, пункт 1 — нет. «Все студенты что-то решили» и «все задачи кем-то решены» — разные требования.

Почему в одном месте →, а в другом &? «Каждый студент» означает: если выбранный предмет студент, проверяем требование. «Есть студент» означает: найденный предмет обязан быть студентом и выполнить требование. Иначе можно было бы случайно выбрать вообще не студента.

Упр. 6Для каждого найдётся большее — или одно больше всех?вместе с аудиторией, 4 мин

Возвращаемся к числам. Проверить две записи на ℕ, затем на области {0,1,2}.

∀x ∃y (x < y)
Для каждого числа x найдётся число y, которое больше него.
Сначала получаем x. После этого подбираем y.

∃y ∀x (x < y)
Есть одно число y, которое больше каждого числа x.
Сначала выбираем y. Оно должно подходить всем x.

На ℕ первая запись истинна. Дали x = 2 — берём y = 3. Дали x = 100 — берём y = 101. Для любого x можем взять x + 1.

На ℕ вторая запись ложна. Предложили y = 100? Проверим x = 101: оно больше 100, требование нарушено. Любого кандидата y опровергаем числом x = y + 1.

На {0,1,2} первая ложна: для x = 2 нет большего числа внутри области. Взять 3 нельзя. Вторая тоже ложна: никакое число не больше всех, включая само себя.

знаки в этой задаче∀x ∃y после x подбираем y∃y ∀x один y для всех xℕ 0, 1, 2, …
запомнить смысл порядка

∀x ∃y: выбираем y после получения x. ∃y ∀x: нужен один общий y.

Первая запись разрешает выбирать разные y, но не требует этого: один предмет можно использовать повторно, если он подходит.

Связь с методичкой. Предложение 3.18, стр. 44, показывает эту разницу на отношении ≤. Там для каждого x можно выбрать y = x, но одного натурального y, не меньшего всех натуральных x, нет. Здесь используем <, чтобы выбирать именно большее число.

4. Кто назначает значение переменной?

Разберём скобки: какие значения задаём снаружи, а какие перебирает «каждый» или «существует».

В записи «x меньше y» надо задать оба числа. В записи «есть x меньше y» число x будет искать сама проверка «существует». А y всё ещё нужно задать снаружи. Например, при y = 5 ответ «да», при y = 0 на натуральных числах — «нет».

R(x,y)       задать снаружи x и y.
∃x R(x,y)    x ищет квантор; задать снаружи только y.
∀x ∃y R(x,y) оба значения перебирают кванторы.

Свободная переменная: значение задаётся снаружи.
Связанное вхождение: им управляет квантор по этой букве.

FV — множество свободных переменных: какие буквы задаём извне.
FV(∃x R(x,y)) = {y}.
Без свободных переменных формула называется предложением.

Свободная y не обязана уже иметь известное значение: мы можем назначить его позже. Слово «свободная» говорит о том, что это значение не выбирает квантор внутри данной формулы.

Упр. 7Проверяем каждую букву по скобкам2 мин самостоятельно, 2 мин сверка

Найти свободные переменные. Обвести часть, которой управляет каждый квантор. Какая формула является предложением?

  1. ∀x (R(x,y) → ∃y P(y)).
  2. (∀x R(x,y)) & (∃y P(y)).
  3. ∀x ∃y R(x,y).

1. Разбираем по шагам. ∀x управляет всей следующей скобкой: x в R связана. ∃y управляет только P(y): y в P связана. До y в R этот квантор не дотягивается. Эта y свободна.

Чтобы одинаковые буквы не мешали, правую связанную y можно назвать z:

∀x (R(x,y) → ∃z P(z))

Теперь видно: снаружи нужна y. Значит, FV = {y}; формула не является предложением.

2. Левая скобка: ∀x управляет R(x,y), но не связывает y. Правая скобка: ∃y управляет P(y). Свободная y слева от этого не меняется. Снова FV = {y}; это не предложение.

3. Значения x перебирает ∀x, а значения y — ∃y. Обе буквы в R связаны. FV = ∅: список пуст. Это предложение; после выбора системы дополнительных чисел снаружи не требуется.

знаки в этой задачеFV свободные переменные∅ пустое множество∀, ∃ каждый, существует
Упр. 8Меняем имя — сохраняем ли вопрос?разбор преподавателя, 3 мин

В ∃x R(x,y) заменить связанную x сначала на z, затем на y. Какой вариант сохраняет смысл?

Для проверки назначим свободной y число 1. Исходный вопрос: «Есть ли натуральное число x меньше 1?» Да, подходит 0.

Было: ∃x R(x,y) Назвали искомое число z: ∃z R(z,y)

Снова спрашиваем: «Есть ли число меньше 1?» Имя искомого числа поменяли, вопрос сохранили. Так менять связанную переменную можно.

Было: ∃x R(x,y) Ошибочно назвали его y: ∃y R(y,y)

6. ПНФ: собираем «каждый» и «существует» в начале

Меняем порядок записи, сохраняя смысл. Сначала читаем по-русски, затем преобразуем.

Предваренная нормальная форма, ПНФ — запись, где все кванторы стоят в начале. Например, «для каждого человека найдётся знакомый» записано как ∀x ∃y R(x,y), если R означает «знает».

Начало ∀x ∃y называется префиксом: «для каждого x найдётся y». Оставшаяся проверка R(x,y) называется матрицей: «x знает y». В ней кванторов уже нет. ПНФ упорядочивает запись; она сама по себе не сообщает, истинна ли формула.

Вынести квантор — значит расширить скобки, которыми он управляет. Проверь новую часть: нет ли там свободной переменной с тем же именем? Иначе она случайно станет связанной. Сначала переименуй связанную переменную в новую букву.

1. «Если A, то B» заменить на «не A или B».
2. Продвинуть «не» внутрь: ¬∀ меняется на ∃¬, ¬∃ — на ∀¬.
3. Разным кванторам дать разные новые имена.
4. Вынести кванторы, проверяя, какие скобки расширяются.

Чтобы опровергнуть «A и B», достаточно нарушения хотя бы одной части. Чтобы опровергнуть «A или B», нужно нарушение обеих. Так переносим «не» внутрь скобок. Два отрицания убирают друг друга.

Используем непустую область: должен быть хотя бы один предмет для выбора. Все правила переноса здесь применяем к непустой области. Порядок «для каждого» и «существует» самостоятельно не меняем: «свой для каждого» и «один для всех» различаются. Определение ПНФ — 3.19; правила — Предложение 3.16; алгоритм — Предложение 3.20, стр. 42–45.

Берём M = {0,1}. P подходит только 0, Q — только 1. Свободной x назначаем 1. Сначала было «P подходит кому-то и Q подходит числу 1» — истина. После ошибки требуется один общий предмет — такого нет.

(∃x P(x)) & Q(x) ∼ (∃u P(u)) & Q(x) ∼ ∃u (P(u) & Q(x))

Во всех строках правильной цепочки: «ищем P-предмет, отдельно проверяем заданный x». В Q(x) нет u, поэтому новые скобки ничего лишнего не связывают.

З3Никто со свойством P не связан со всеми4 мин

¬∃x (P(x) & ∀y R(x,y)) — «нет предмета со свойством P, для которого R выполнено с каждым y». Привести к ПНФ; найти начало с кванторами, оставшуюся проверку и свободные переменные.

¬∃x (P(x) & ∀y R(x,y)) ∼ ∀x ¬(P(x) & ∀y R(x,y)) ∼ ∀x (¬P(x) ∨ ¬∀y R(x,y)) ∼ ∀x (¬P(x) ∨ ∃y ¬R(x,y)) ∼ ∀x ∃y (¬P(x) ∨ ¬R(x,y))

По шагам: «никто не подходит» → «каждый не подходит» → «либо нет P, либо не все связи R» → «либо нет P, либо найдётся нарушенная связь».

Переносим y: в P(x) буквы y нет. Если P(x) ложно, подходит любой y; иначе нужен y с неверным R. Префикс ∀x ∃y — «для каждого x найдётся y». Матрица ¬P(x) ∨ ¬R(x,y) — «нет P или нет связи R». FV = ∅: свободных переменных нет.

знаки в этой задаче¬ не∀, ∃ для каждого, существует∼ формулы эквивалентны
З4Убираем «если», сохраняя заданную y4–5 мин

(∀x P(x)) → ∃x R(x,y) — «если всем подходит P, то найдётся x, связанный отношением R с заданным y». Привести к ПНФ. Можно ли оставить один квантор?

(∀x P(x)) → ∃x R(x,y) ∼ (¬∀x P(x)) ∨ ∃x R(x,y) ∼ (∃x ¬P(x)) ∨ ∃x R(x,y) ∼ (∃u ¬P(u)) ∨ ∃v R(v,y) ∼ ∃u ∃v (¬P(u) ∨ R(v,y))

Сначала «если» заменяем на «не… или…». Затем «не всем подходит P» заменяем на «кому-то не подходит P». Переименовываем две разные x в u и v. При переносах u нет справа, v нет слева, поэтому смысл сохраняется: «есть предмет без P или есть предмет, связанный с заданным y». Свободна только y.

Можно короче: ∃x (¬P(x) ∨ R(x,y)) — «найдётся предмет, которому не подходит P или для которого выполнено R(x,y)». Достаточно одного свидетеля любой половины «или».

С «и» это не работает: (∃x P(x)) & (∃x Q(x)) допускает разные предметы для двух свойств; ∃x (P(x) & Q(x)) требует общий предмет. Вспомни футболиста и хоккеиста.

«И», «или», «не», «для всех», «существует»
ЗаписьКак читать и что проверять
&«И». Обе части должны быть истинны. Название: конъюнкция.
∨«Или». Достаточно хотя бы одной истинной части; обе тоже могут быть истинны. Название: дизъюнкция.
¬«Не». Меняет истину на ложь и ложь на истину. Название: отрицание.
→«Если…, то…». Нарушено только тогда, когда условие выполнено, а требуемый результат — нет. Название: импликация.
∀x«Для каждого икс из нашей области». Должны подойти все. Название: квантор всеобщности.
∃x«Есть хотя бы один икс из нашей области». Достаточно найти один подходящий предмет. Название: квантор существования.
∼«Эквивалентно». Две формулы дают одинаковую истинность во всех допустимых системах и при всех подстановках. Это знак нашего рассуждения о формулах.

Как читать длинную запись из методички

В определении 3.5 система только с функциями и константами называется алгеброй, а система только с предикатами — моделью. В §3.3 слово «модель» используется шире, в том числе для системы с функциями. В наших объяснениях говорим «система»: область вместе с выбранным смыслом букв.

Пусть наша система — натуральные числа, а γ назначает x число 2. Тогда запись t𝔄[γ] означает «значение выражения t при выбранных правилах и этой подстановке». Если t — это f(x), а f прибавляет единицу, получаем 3.

𝔄 ⊨ φ[γ] читается: «в нашей системе формула φ истинна при подстановке γ». Знак ⊭ сообщает, что при этой подстановке формула ложна.

γ[x := a] означает: «используем прежнюю подстановку, но теперь x получает предмет a». Значения остальных переменных сохраняем.

x ∉ FV(ξ) означает: «в соседней формуле ξ нет свободной x». Это условие проверяем, прежде чем расширять область действия квантора по x.

Q₁x₁ … Qₙxₙ ψ — общий шаблон ПНФ. Каждая Q здесь означает один из двух знаков: ∀ или ∃. После них стоит формула ψ без кванторов. В другой задаче буква Q(x) может обозначать предикат; её смысл всегда указан в условии.
