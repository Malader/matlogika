Шпаргалка: предметы, формулы и кванторы

Знаки главы 3 в обозначениях пособия. Под каждой задачей есть собственная подсказка: справочник не нужно держать открытым.

Два разных вида значений. Предметная переменная x обозначает элемент выбранного множества. Терм f(x) тоже получает элемент. Формула P(f(x)) получает истину или ложь. Квантор связывает предметную переменную, а не букву, обозначающую целую формулу.

Три пары, которые проверяем всю пару

Терм / формула

f(c) обозначает предмет. P(f(c)) утверждает что-то про этот предмет. В вопросе «чему равно?» ждём элемент; в вопросе «истинно ли?» — истину или ложь.

Символ / его значение

R — часть языка. R𝔄 — конкретное отношение. Один язык может описывать разные системы: на тех же натуральных числах R можно понять как «меньше» или как «делится на».

Формула / утверждение о формуле

∀x P(x) — формула. 𝔄 ⊨ ∀x P(x) — наше сообщение о её истинности в системе 𝔄. φ ∼ ψ — сообщение об эквивалентности; знак ∼ не добавляет новую связку к языку.

Упр. 1Разогрев: что можно понять без области предметовустно, 2 мин

В каком случае ложна A → B? Что означает ¬(A & B)? Можно ли сразу сказать, истинна ли запись x < 3?

A → B ложна только при A = и, B = л. ¬(A & B) истинна, когда хотя бы одна часть ложна; обе ложные части тоже подходят.

У x < 3 без назначения x ещё нет определённого значения истинности. На натуральных числах при x = 1 получаем истину, при x = 5 — ложь. Сам текст формулы при этом не меняется.

Вопрос вдогонку: «А у ∃x (x < 0) значение уже есть?» После выбора области — да. На натуральных числах это ложь, на целых — истина. Область нужна даже тогда, когда свободных переменных нет.

Сигнатура похожа на список объявлений: P ждёт один аргумент, R — два, f — один. Но из этого списка ещё не известно, что эти имена означают. Система назначает им значения.

Показать три строки: P(2), R(2,5), f(2). Спросить, где ответ предмет, а где истина или ложь. Ожидаем: у первых двух — значение истинности, у последней — число 3.

Отношение можно хранить как список подходящих наборов. Для «меньше» пара (2,5) подходит, пара (5,2) не подходит. Функция обязана по каждому входу вернуть ровно один элемент нашей области. Если по одному входу получаются два разных выхода, это уже не функция.

Почему проверяем замкнутость. На M = {0,1,2} правило f(a) = a + 1 не задаёт функцию из M в M: для a = 2 результат 3 лежит за пределами M. Можно задать другую функцию: 0 переходит в 1, 1 в 2, 2 в 0.

Терминология пособия. В Определении 3.5 «модель» — система только с предикатами, «алгебра» — только с функциями и константами. В §3.3 автор использует слово «модель» и для общей алгебраической системы. Здесь следуем этому употреблению, а в точных определениях говорим «система».

2. Термы и атомарные формулы: сначала собрать, потом вычислить

Научиться отличать имя предмета от утверждения. Показать рекурсивное построение и вычисление снизу вверх.

Опр. 3.6-3.7, стр. 38-39
Термы:
  x, y, z, … и константы;
  f(t) — терм, если t терм и f одноместен;
  других термов нет.

Атомарные формулы:
  t₁ = t₂;    P(t);    R(t₁,t₂).

Из формул φ, ψ строим:
  (φ & ψ), (φ ∨ ψ), (φ → ψ), ¬φ, ∀x φ, ∃x φ.

Терм → элемент M.       Формула → и или л.

Атомарная формула — самое маленькое утверждение, без логических связок и кванторов. Внутри неё могут быть длинные термы. Слово «атомарная» не означает «короткая».

Пройти пальцем по R(f(f(x)),c): x — терм, f(x) — терм, f(f(x)) — терм, c — терм, затем R получает два терма и выдаёт формулу. Сначала проверяем разрешённость записи, затем назначаем значения. Это два разных действия.

Для программистов достаточно одной аналогии: терм имеет тип «предмет области», формула — тип «значение истинности». У f(P(x)) ошибка уже на уровне этих типов.

3. Кванторы: кто выбирает предмет и в каком порядке

Перевести три фразы с русского и разобрать разницу между «каждому свой» и «один для всех». Скобки и область предметов проговариваем вслух.

∀x φ(x)   для каждого x из M истинна φ(x)
∃x φ(x)   есть хотя бы один x из M, при котором истинна φ(x)

∀: чтобы доказать — охватить все случаи;
   чтобы опровергнуть — достаточно одного контрпримера.
∃: чтобы доказать — достаточно одного свидетеля;
   чтобы опровергнуть — исключить все возможные случаи.

Квантор не сообщает, что M состоит из чисел или студентов.
Это выбирается до чтения формулы.

Существование не означает единственность. Если подходит один предмет, формула истинна. Если подходят пять, она по-прежнему истинна.

Для «все студенты» у нас два варианта: выбрать областью только студентов или работать в более широкой области и добавить условие «если x студент». Без этого условия мы можем случайно потребовать сдачу задач от самих задач.

Упр. 5Студенты и задачи: перевод на язык формул2 мин самостоятельно, 4 мин общий разбор

Область M содержит людей и задачи. S(x) — «x студент», T(y) — «y задача», L(x,y) — «x решил y». Записать:

  1. Каждый студент решил хотя бы одну задачу.
  2. Есть студент, не решивший ни одной задачи.
  3. Каждую задачу решил хотя бы один студент.

1. Каждый студент решил хотя бы одну задачу. Сначала выбирается произвольный предмет x. Если он студент, требуется подобрать задачу y, решённую этим студентом:

∀x (S(x) → ∃y (T(y) & L(x,y)))

Внешняя импликация отсеивает предметы, которые не являются студентами. Внутреннее «и» требует сразу двух вещей: выбранный y действительно задача и x её решил.

2. Есть студент, не решивший ни одной задачи. Нужен один свидетель x, который студент и для которого не существует решённой задачи:

∃x (S(x) & ¬∃y (T(y) & L(x,y)))

Другой правильный ответ: ∃x (S(x) & ∀y (T(y) → ¬L(x,y))). Равносильность этих записей разберём через отрицание квантора.

3. Каждую задачу решил хотя бы один студент. Первым выбираем задачу y, затем подбираем студента x:

∀y (T(y) → ∃x (S(x) & L(x,y)))
